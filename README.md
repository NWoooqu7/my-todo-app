# My Todo App

ブラウザだけで動く、シンプルなTodoアプリです。
HTML・CSS・JavaScriptを1つのHTMLファイルにまとめているため、ビルドやインストールは必要ありません。

## 現時点でできること

- Todoの追加
- チェックボックスによる完了・未完了の切り替え
- 完了したTodoの打ち消し線表示
- Todoの削除
- Supabaseを使ったTodoのクラウド保存
- メールアドレスとパスワードによるユーザー登録・ログイン
- パスワードを忘れた場合の再設定

## 使い方

`outputs/index.html`をブラウザで開いてください。

パスワード再設定メールのリンクは、GitHub Pagesで公開したアプリへ戻ります。
SupabaseのRedirect URLsに公開先URLを登録して使用してください。
